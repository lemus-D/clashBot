# EasyOCR was here to read the six tower-HP numbers, after Tesseract proved
# unable to (it topped out at 9 of 12 known readings and emitted confident
# wrong values like 1512 -> 112). It is gone because the numbers are gone:
# tower HP is now the fill fraction of the on-screen HP bar, measured
# geometrically in src/vision/towers.py. That removed a ~100 MB model
# download, ~84 ms/cycle, and a recogniser that could be confidently wrong.
# If you have a stale ~/.EasyOCR directory from an older checkout, it is now
# dead weight and safe to delete.
#
# The match TIMER is the only remaining OCR, and uses Tesseract.
# tesserocr binds libtesseract in-process, so the persistent
# handle in src/vision/ocr.py loads tessdata once instead of spawning a
# tesseract.exe every cycle (~200 ms -> ~0). It replaced pytesseract entirely.
#
# WINDOWS: PyPI ships NO Windows wheels for tesserocr and the sdist needs a
# full C++ toolchain, so install the prebuilt wheel below. It bundles
# libtesseract 5.5.2 + leptonica 1.87.0; only the language data comes from the
# local Tesseract-OCR install (found via PATH, or TESSDATA_PREFIX). Pick the
# cpXXX matching your Python from
# https://github.com/simonflueckiger/tesserocr-windows_build/releases
# On Linux/macOS plain `pip install tesserocr==2.10.0` gets a PyPI wheel.
